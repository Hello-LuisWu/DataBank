# ls

显示指定目录/文件信息及属性

语法:

```shell
ls [选项] [file/directory]
```

选项:

|   选项 | 说明                 |
| ---: | :----------------- |
| `-a` | 显示所有文件(包括隐藏文件)     |
| `-l` | 以长格式 (列表形式) 列出文件信息 |
| `-d` | 查看目录本身, 而不是里面的文件   |
| `-i` | 显示文件i节点信息, 文件的唯一ID |
| `-t` | 按修改时间排序            |
| `-S` | 按大小排序              |
| `-p` | 在目录名的最后加上 `/`      |

**实例:**

``` shell
ls -lah *.html
```

**以列表形式查看文件&隐藏文件:** 

```shell
ls -lha 
```

**文件信息:**

```sh
drwxr-xr-x   9 luis  staff   288B  7 31 15:07 .
drwx------  18 luis  staff   576B  7 22 07:25 ..
-rw-r--r--@  1 luis  staff   6.0K  7 22 05:57 .DS_Store
drwxr-xr-x  14 luis  staff   448B  8  6 17:39 .git
-rw-r--r--   1 luis  staff    12K  8  7 01:30 README.md
drwxr-xr-x   9 luis  staff   288B  8  3 14:00 img
-rw-r--r--   1 luis  staff    73B  7 24 13:08 init.lua
-rw-r--r--   1 luis  staff   4.1K  8  3 08:35 lazy-lock.json
drwxr-xr-x   5 luis  staff   160B  7 31 15:11 lua
```

**第一组**:
- `d` 开头:表示目录
- `-` 或 `.` 开头: 表示普通文件
- `l` 开头: 软连接
- 2-4位: User 所有者权限,文件创建者的权限
- 5-7位: Group 所属组权限,
- 8-10位: Other 其他人权限  
    用户三大权限:
    - r(4): read, 读取权限
    - w(2): write, 写入权限
    - x(1): execute, 运行权限,一般是二进制文件和sh脚本才有的权限

**第二组**:

- 文件被调用的次数

**第三组:** 

- 文件的所有者, 创建文件的人, 只能有一个所有者

**第四组:**

- 所属组,只能有一个, 规定组里的人可以有哪些权限

**第五组:** 

- 文件大小

**第六组:** 

- 文件最后修改日期

**第七组** 

- 文件名
