# ls

用于**列出目录内容和文件信息**。

它是 Linux 中使用频率最高的命令之一，常用于查看：

- 文件列表
- 文件权限
- 文件大小
- 文件时间
- 隐藏文件
- 目录结构

## 语法

```shell
ls [选项] [file/directory]
```

## 选项

|   选项 | 说明                   | 示例           |
| ---: | :------------------- | ------------ |
| `-a` | 显示所有文件(包括隐藏文件)       | `ls -a`      |
| `-l` | 以长格式 (列表形式) 列出文件信息   | `ls -l`      |
| `-d` | 查看目录本身, 而不是里面的文件     | `ls -d /etc` |
| `-i` | 显示 inode 编号, 文件的唯一ID | `ls -i`      |
| `-t` | 按修改时间排序              | `ls -t`      |
| `-S` | 按大小排序                | `ls -S`      |
| `-p` | 在目录名的最后加上 `/`        | `ls -lp`     |
| `-h` | 文件大小以易读单位显示          | `ls -lh`     |
| `-Q` | 目录/文件名加双引号           | `ls -Q`      |
| `-r` | 反向排序                 | `ls -Sr`     |

## 实例

```sh
ls -lah *.html
```

**以列表形式查看文件&隐藏文件:** 

```sh
ls -lha 
```

---

**文件信息:**

```sh
-rw-r--r--  1 luis developers  1024 Aug  4 10:20 test.txt
```

- `-rw-r--r--` : 文件类型/权限
	- `-` : 第一个字符表示类型：
		- `d` 开头:表示目录
		- `-` 或 `.` 开头: 表示普通文件
		- `l` 开头: 软连接
		- `c` 字符设备
		- `b` 块设备
		- `s` socket
		- `p` 管道
	- `rw-` : 2-4位: User 所有者权限。权限包含:
		- `r` (4): re`ad, 读取权限
		- `w` (2): write, 写入权限
		- `x` (1): execute, 运行权限,一般是二进制文件和sh脚本才有的权限
		- `-` 无权限`
	- `r--` : 5-7位: Group 所属组权限
	- `r--` 8-10位: Other 其他人权限  
- `1` : 第二组: 硬链接数量
- `luis` : 第三组: 文件的所有者, 创建文件的人, 只能有一个所有者
- `developers` : 第四组: 所属主组, 主组只能有一个, 规定组里的人可以有哪些权限
- `1024` : 第五组: 文件大小
- `Aug 4 10:20` : 第六组: 文件最后修改日期
- `test.txt` : 第七组: 文件名
