# cd

## 语法

```sh
cd [参数] [目录]
```

## 选项

|   选项 | 说明                  | `cd ~`  |
| ---: | :------------------ | ------- |
|  `~` | 代表家目录,如 root 和 home | `cd .`  |
|  `.` | 代表当前目录              | `cd .`  |
| `..` | 返回上一级目录             | `cd ..` |
|  `-` | 上次所在的目录, 与上一个目录来回切换 | `cd -`  |
|  `/` | 根目录，也代表绝对路径         | `cd /`  |

## 实例

### 01 ~ 相对路径

```sh
# 快速返回家目录
cd ~

# 进入家目录下的 .config 目录
cd ~/.config
```

### 02 /  绝对路径

```sh
# 进入根目录
cd /

# 进入 根目录下的 etc 目录
cd /ect
```
