# 正则表达式（Regular Expression, Regex）元字符。

常用于：
- `grep`
- `sed`
- `awk`
- `vim/nvim 搜索替换`
- 编程语言正则

## 选项

| 符号       | 名称   | 作用                         | 示例                       | 匹配                          |
| -------- | ---- | -------------------------- | ------------------------ | --------------------------- |
| `.`      | 点号   | 匹配任意一个字符                   | `a.c`                    | abc、a1c                     |
| `^`      | 行首锚定 | 匹配字符串开头                    | `^root`                  | root 开头                     |
| `$`      | 行尾锚定 | 匹配字符串结尾                    | `bash$`                  | bash 结尾                     |
| `*`      | 星号   | 前一个字符出现 0 次或多次             | `ab*c`                   | ac、abc、abbc                 |
| `+`      | 加号   | 前一个字符出现 1 次或多次             | `ab+c`                   | abc、abbc                    |
| `?`      | 问号   | 前一个字符出现 0 次或 1 次           | `ab?c`                   | ac、abc                      |
| `\|`     | ...  | **或（OR）** 操作符，匹配其左右两边的条件之一 | 两者任选其一                   | `cat\|dog` 匹配 "cat" 或 "dog" |
| `{n}`    | 次数限定 | 前一个元素精确出现 n 次              | `[0-9]{4}`               | 四位数字。                       |
| `{n,m}`  | 范围限定 | 前一个元素**出现 n 到 m 次**        | `[a-z]{2,4}` 匹配两到四位小写字母。 | 匹配两到四位小写字母：ok 或 sky 或 mode  |
| `{n,}`   |      | 前一个元素**至少出现 n 次**          | `a{2,}`                  | "aa" 或 "aaaaa"。             |
| `[...]`  | 字符集合 | 匹配括号内任意一个字符                | `[abc]` 匹配任意一个小写元音字母。    | apple、 book、 cat            |
| `[^...]` | 排除集合 | 不匹配指定字符                    | `[^0-9]`                 | 排除数字                        |
| `(...)`  | 分组   | 将括号内的模式视为一个整体              | `(ab)+`                  | "ab", "abab", ...。          |
| `\`      | 反斜杠  | 转义字符                       | `\.`                     | 匹配字面意义上的点号 "."。             |


## 实例

### 1 普通字符匹配

```sh
# 只匹配 abc 单词：
abc

# 例如以下文本：
hello abc world

# 只匹配：
abc
```

### 2 点号 `.`

匹配任意一个字符。

```sh
a.c

# 匹配：
abc
a1c
a-c
a c
```

### 3 `^` 匹配开头（start）

```sh
# 文本：
root:x:0
user:x:1000
root_test

# 命令：
grep "^root" file

# 结果：
root:x:0
root_test
```

### 4 `$` 匹配结尾（end）

匹配结尾。

```sh
# 文本：
hello linux
linux hello
hello world

# 命令：
grep "hello$" file

# 结果：
linux hello
```

### 5 星号 `*`

`*` 前面的字符出现 0 次或多次

```sh
ab*c

# 匹配：
ac
abc
abbc
abbbc
```

> 注意：匹配的是 `*` 前面的字符。也就是 `b` 这个字符。所以上面代码中，b 可以没有，也可以多个

### 6 加号 `+`

`+` 前一个字符出现 1 次或多次

> 注意：grep 默认不支持，需要 `grep -E`

```sh
ab+c

# 匹配：
abc
abbc
abbbc

# 不匹配：
ac
```

### 7 问号 `?`

`?` 前一个字符出现 0 次或 1 次

```sh
colou?r

# 匹配：
color
colour
```

### 8 花括号 `{}`


```sh
a{3}

# 匹配：
aaa
```

前一个元素精确出现 3 次

#### 8.1 `{n,m}` 范围限定

```sh
a{2,5}

# 匹配：
aa
aaa
aaaa
aaaaa
```

前一个元素出现 2 到 5 次

#### 8.2 `{n,}` 最少次数

```sh
a{3,}

# 匹配：
aaa
aaaa
aaaaa
aaaaaa
.........
```

前一个元素至少出现 3 次

### 9 字符集合 `[ ]`

指定字符

```sh
[abc]

# 匹配：
apple
book
cat
```

匹配括号内任意一个字符

#### 9.1 字符范围

```sh
# 小写字母：
[a-z]

# 大写字母：
[A-Z]

# 数字：
[0-9]
```

#### 9.2 组合

```sh
[a-zA-Z0-9]

# 匹配：
a
B
9
```

### 10 排除集合 `[^]`

不匹配指定字符

```sh
[^0-9]
```

不匹配数字，而匹配符号、字母

### 11 分组 `()`

将多个字符组合。

```sh
(ab)+

# 匹配：
ab
abab
ababab
```

将括号内多个字符视为一个整体。

### 11.1  没有括号

```sh
ab+

# 匹配：
ab
abb
abbb
```

不加括号等于表示：a + 多个 b

### 12 或 `|`

任选一个。匹配其左右两边的条件之一

```sh
cat|dog

# 匹配：
cat
dog
```

#### 12.1 与 `()` 组合

```sh
^(cat|dog)$
```

只匹配 cat 或者 dog

### 13 `\` 转义字符

用于匹配特殊字符。

```sh
# 显示真正的 .
\.

# 例如显示 ip 地址
192\.168\.1\.1
```

常见转义

| 写法   | 含义  |
| ---- | --- |
| `\.` | 点   |
| `\*` | 星号  |
| `\+` | 加号  |
| `\?` | 问号  |
| `\(` | 左括号 |
| `\)` | 右括号 |
| `\\` | 反斜杠 |

#### 13.2 预定义字符 / 简写元字符（PCRE/awk/grep‑P）

 `\d` **数字：**

匹配数字

```sh
# 匹配 [0-9]
\d

# 匹配：
# 123
# 456
\d\d\d
``` 

`\w` **字符:**

匹配大小写字母、数字和下划线

```sh
# 匹配 [a-zA-Z0-9_]
\w

# 匹配：
hello
user_1
```

`\s` **匹配空白字符：**

匹配空格、Tab、换行

```sh
# 匹配 [ \t\n\r]
\s

# 例如：
Hello\sLuis\sWu

# 匹配：
Hello Luis Wu
```

`\b` **单词边界：**

单词边界匹配

```sh
# 单词：
abcdefghijk

# 匹配 fjh
\bfgh\b

# 匹配：
fgh
```

**简写元字符列表：**

| 简写   | 含义                                 | 等价字符集           |
| ---- | ---------------------------------- | --------------- |
| `\d` | 数字                                 | `[0-9]`         |
| `\D` | 非数字                                | `[^0-9]`        |
| `\w` | 单词字符 (大小写字母数字下划线)                  | `[a-zA-Z0-9_]`  |
| `\W` | 非单词字符                              | `[^a-zA-Z0-9_]` |
| `\s` | 空白（空格、tab、换行、回车）                   | `[ \t\n\r]`     |
| `\S` | 非空白字符                              | `[^ \t\n\r]`    |
| `\b` | 单词边界（字首 / 字尾零宽）例`\bcat\b`只匹配独立 cat | cat             |
| `\B` | 非单词边界                              |                 |
| `\t` | Tab 制表符                            |                 |
| `\n` | 换行符                                |                 |
| `\r` | 回车符                                |                 |

## 通配符 vs 正则区别

通配符用于命令批量处理文件，正则用于字符串匹配

很多人容易混淆：

| 功能   | 通配符     | 正则   |
| ---- | ------- | ---- |
| 任意字符 | `*`     | `.*` |
| 一个字符 | `?`     | `.`  |
| 开头   | ❌       | `^`  |
| 结尾   | ❌       | `$`  |
| 或    | `{a,b}` | `a   |
| 分组   | `{}`    | `()` |
