# Linux 命令中括号的使用技巧与原理

Linux 命令中经常看到各种括号：

| 符号     | 名称      | 作用                                          | 示例                            |
| ------ | ------- | ------------------------------------------- | ----------------------------- |
| `{}`   | 花括号展开   | 生成字符串                                       | `file{1..5}`                  |
| `()`   | 子 Shell | 隔离环境                                        | `(cd /tmp)`                   |
| `$( )` | 命令替换    | 获取命令输出                                      | `$(date)`                     |
| `[]`   | 条件测试    | 判断条件                                        | `[ -f file ]`                 |
| `[[]]` | 高级判断    | bash 条件                                     | `[[ $a == *.txt ]]`           |
| `<( )` | 进程替换    | 把命令结果当文件                                    | `diff <(ls a) <(ls b)`        |
| `>\|`  | ....... | 强制覆盖，就算 shell 设置 noclobber（禁止覆盖已有文件），强制覆写文件 | `echo hello >\| file`         |
| `>`    | 覆盖重定向   | 清空文件原有内容，写入新内容；                             | `echo "hello world" > a.txt`  |
| `>>`   | 追加重定向   | 在文件尾部追加内容，不会清空旧数据；                          | `echo "hello world" >> a.txt` |
| `\|`   |         | 标准输出传给下个命令标准输入                              |                               |
|        | 旧命令替换   | 执行命令                                        | `date`                        |

非 Linux 命令本身语法，大都是 Shell（bash/zsh 等）的语法规则。

执行命令前，会先进行「解析和展开（expansion）」，括号就是告诉 Shell 如何组织、匹配、生成文本。

流程：

```
输入命令
    ↓
Shell 解析语法
    ↓
变量展开
    ↓
通配符展开
    ↓
括号展开
    ↓
生成最终命令
    ↓
执行程序
```

## 一、{} 花括号（Brace Expansion）

**作用：** 批量生成字符串 

这是 Linux 中最常用的括号技巧。

### 1. 创建多个文件

```sh
touch file{1..5}.txt

# 相当于:
touch file1.txt file2.txt file3.txt file4.txt file5.txt
```

格式：`{开始..结束}`

例如：`{01..10}`

生成：

```
01
02
03
04
05
06
07
08
09
10
``` 



### 2. 字母展开

```sh
echo {a..z}

# 结果：
a b c d e ... z
```

创建章节：

```sh
mkdir chapter-{A..F}

# 生成：
chapter-A
chapter-B
chapter-C
...
```

### 3. 指定步长

```sh
{start..end..step}
```

求奇数：

```sh
echo {1..10..2}

# 结果：
1 3 5 7 9
```

求偶数：

```sh
echo {0..10..2}

# 结果：
0 2 4 6 8 10
```

### 4. 多个选项展开

```sh
echo {apple,banana,orange}

# 结果：
apple banana orange
```

创建多目录:

```sh
mkdir test/{a,b,c}

# 结果：
test/
	|- a/
	|- b/
	|- c/
```

### 5. 嵌套展开

```sh
echo {a,b}/{1,2}

# 展开：
a/1
a/2
b/1
b/2
```

```sh
mkdir -p project/{src,docs}/{test,build}

# 展开：
project/src/test
project/src/build
project/docs/test
project/docs/build
```

## 二、() 小括号

有两个作用：
1. 创建子 Shell（用于 shell 环境隔离）
2. 命令分组

### 1. 子 Shell

```sh
(cd /tmp && ls)
```
 
后台执行的是 `cd /tmp` 和 `ls` , 但是所在目录不会改变，相当于新打开一个 shell ，执行完命令后就关闭 shell，当前 shell 不受影响。


### 2. 命令分组

```sh
(echo hello; echo world)

# 输出:
hello
world
```

等价于：

```sh
{
echo hello
echo world
}
```

`;` 与 `&&` 的区别：

| 符号   | 名称        | 执行规则                  | 作用                   | 适用场景            | 示例                              |
| ---- | --------- | --------------------- | -------------------- | --------------- | ------------------------------- |
| `&&` | 逻辑‑与（短路与） | 前命令成功 (退出码 0)，才执行后方命令 | 前面的命令执行失败，后面的命令则不会执行 | `&&` 前后会被视作一条命令 | `cd /xxx && pwd`，cd 失败 pwd 不会运行 |
| `;`  | 命令分隔符     | 无条件顺序执行前、后命令          | 前置执行成功之后才可执行后续操作     | 执行互不依赖的多条指令     | `cd /xxx ; pwd`，cd 报错 pwd 依旧执行  |


## 三、$( ) 命令替换

作用：执行命令，并把输出结果替换回来。

> 注：命令替换每次都会新建子进程，循环里频繁 `$()` 性能差。

```sh
echo $(date)
```

将 `date` 执行的结果返回到 echo 的标准输入里

### 1. 创建日期目录

```sh
mkdir backup-$(date +%F)

# 展开：
mkdir backup-2026-08-06
```

### 2. 变量赋值

```sh
today=$(date +%Y-%m-%d)

# 结果：
today="2026-08-06"
```

### 3. 命令支持嵌套

```sh
echo $(basename $(pwd))
```

## 四、[ ] 中括号

主要用于：
1. 条件判断
2. 字符匹配

### 1. 条件判断

```sh
[ 条件 ]

# 例如：
if [ -f test.txt ]; then
    echo "文件存在"
fi
```

> 注意: `[` 实际是一个命令，所以 `[ ... ]` 中括号内必须要有空格！ 

```sh
# 正确案例:
[ -f file ]

# 错误案例
[-f file]
```

**常用判断:**

| 条件  | 含义    |
| --- | ----- |
| -f  | 普通文件  |
| -d  | 目录    |
| -e  | 存在    |
| -r  | 可读    |
| -w  | 可写    |
| -x  | 可执行   |
| -z  | 字符串为空 |
| -n  | 字符串非空 |

判断目录是否存在：

```sh
if [ -d /tmp ]; then
    echo yes
fi
```

## 五、\[\[ \]\] 高级条件判断

### 1. \[ \] 和 \[\[ \]\] 完整区别:

- `[ ]`：**POSIX 标准命令**（等价于 `test` 程序），所有 shell (sh、dash、bash、zsh) 通用，语法严格死板
- `[[ ]]`：**Bash/Zsh 内置关键字**，bash 扩展语法，功能更强、容错更高、写法舒服

`[ ]` **括号两边必须空格**，少空格直接报错:

```sh
if [! -d "$dir" ];then # 错误
if [ ! -d "$dir" ];then# 正确
```

`[[ ]]` 宽松很多，但规范依旧建议加空格:

```sh
[[! -d "$dir" ]] # 两边没空格不会语法报错 
[[ ! -d "$dir" ]] # 标准写法
```

### 2. 支持正则

```sh
if [[ $name =~ ^user ]]; then
    echo match
fi

# 匹配:
user001
userabc
```

### 3. 支持通配符

```sh
[[ $file == *.txt ]]

# 匹配所有 .txt 文件
```

## 六、<( ) 进程替换

高级 Bash/Zsh 功能。把命令输出伪装成文件。

```sh
diff <(ls a) <(ls b)
```

比较两个目录：Shell 会生成 `/dev/fd/63` `/dev/fd/64`, 然后 `diff 文件1 文件2`

## 七、>| 强制覆盖

```sh
echo hello >| file
```

## 九、括号组合技巧

**1. 批量创建项目:**

```sh
mkdir -p app/{bin,conf,logs,data}
```

**2. 创建多个配置文件：**

```sh
touch nginx.{conf,log,bak}
```

**3. 日期备份**

```sh
cp file.txt file-$(date +%F).bak
```
