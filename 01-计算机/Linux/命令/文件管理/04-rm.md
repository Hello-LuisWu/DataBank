# rm

remove, 删除目录/文件

## 选项

| 选项           | 说明                      | 示例               |
| ------------ | ----------------------- | ---------------- |
| `-r` \/ `-R` | 递归操作, 同时删除目录和目录下的文件和子目录 | `rm -r dir`      |
| `-f`         | 强制删除，不提示，不报不存在错误        | `rm -f file.txt` |
| `-i`         | 删除前询问确认                 | `rm -i file.txt` |
| `-v`         | 显示删除过程                  | `rm -v file.txt` |
| `...`        | ...                     | `...`            |

## 实例

### 1 删除文件

```sh
rm test.txt

# 删除多个文件
rm a.txt b.txt c.txt
```

### 2 删除前确认

```sh
rm -i important.txt
```

按 `y` 确认删除，或 按 `n` 保留

适合：
- 删除重要文件
- 防止误删

### 3 强制删除

```sh
rm -f test.txt
```

不询问删除，若删除的文件不存在也不会报错

### 4 递归删除目录

```sh
rm -r project

# 目录结构
project
├── a.txt
├── b.txt
└── src
    └── main.c
```

删除 `project` 目录及里面的文件和目录

### 5 强制递归删除目录

```sh
rm -rf build

# 目录结构：
build/
├── 文件
├── 子目录
└── 所有内容
```


### 6 显示删除过程

```sh
rm -rv test

# 输出：
removed 'test/a.txt'
removed 'test/b.txt'
removed directory 'test'
```

### 7 通配符删除

相关文档：[[Linux 中通配符的应用]] 、 [[02-Linux 中连接多个命令的符号详解]] 、 [[01-命令中括号的使用技巧详解]]

#### 7.1 删除所有 txt 文件

```sh
rm *.txt
```

#### 7.2 删除日志文件

```sh
rm *.log
```

#### 7.3 删除指定编号文件

```sh
rm file{1..5}.txt
```

#### 7.3.2 删除指定字符范围的文件

```sh
rm -rf {c..j}.txt
```

删除 字母顺序 c 到 j 范围内的 txt 文件

#### 7.4 删除隐藏文件

```sh
rm -rf .*
```

#### 7.5 删除所有文件/目录（包括隐藏的）

```sh
rm -rf *
```
