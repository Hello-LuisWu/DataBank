# find

查找目录/文件

## 语法 

```shell
find [path] [option] [filename]
```

---

## 选项

| 选项       | 说明                                      |
| -------- | --------------------------------------- |
| `-name`  | 按文件名查找, 区分大小写                           |
| `-iname` | 按文件名查找,不区分大小写                           |
| `-type`  | 按文件类型查找, 如: f 代表普通的文件. d 代表目录. l 代表链接文件 |
| `-user`  | 按文件所属者查找                                |
| `-group` | 按文件所属组查找                                |
| `-size`  | 按文件大小搜索                                 |

---

## 实例

**01.** 查找当前目录下名为 file.txt 的文件：

```sh
find . -name file.txt
```

**02.** 将当前目录及其子目录下所有文件后缀为 .c 的文件列出来:

```sh
find . -name "*.c"
```

**03.** 将当前目录及其子目录中的所有文件列出：
```sh
find . -type f
```

**04.** 查找 /home 目录下大于 1MB 的文件：

```sh
find /home -size +1M
```

**05.** 查找 /var/log 目录下在 7 天前修改过的文件：

```sh
find /var/log -mtime +7
```
