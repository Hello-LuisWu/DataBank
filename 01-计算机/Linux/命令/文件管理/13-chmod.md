# chmod

change mode, 用于**修改文件或目录的权限**。

Linux 文件权限决定：

- 谁可以读取文件
- 谁可以修改文件
- 谁可以执行文件
- 谁可以进入目录

## 语法

```shell
chmod [option] [path/file]
```

## 选项

| 选项   | 说明          | 示例                  |
| ---- | ----------- | ------------------- |
| `-R` | 递归修改目录及子文件  | `chmod -R 755 dir`  |
| `-c` | 只显示发生变化的文件  | `chmod -c 755 file` |
| `-f` | 忽略错误信息      | `chmod -f 755 file` |
| `-v` | 显示权限变更的详细资料 | `chmod -v 755 file` |

## 实例

不同用户对应的权限组,如图所示:

![wjqx](wjqx.png)

**用户类型:**

1. u(user): 所属用户, 文件的创建者
2. g(group): 所属组,规定群组内用户的权限
3. o(other): 其他用户,不属于user和group,就自动归属于其他用户
4. a(all): 所有用户

**权限类型:**

| 代表字符       | 代表数字 | 权限  | 对文件的权限       | 对目录的权限            |
| ---------- | ---- | --- | ------------ | ----------------- |
| r(read)    | 4    | 读取  | 读取文件的内容      | 可用 ls 列出目录内的文件和目录 |
| w(write)   | 2    | 写入  | 增加,删除,修改文件内容 | 创建,删除目录内的文件和目录    |
| x(execute) | 1    | 运行  | 执行运行文件       | 可以 cd 进入目录        |
|            | 0    |     | 清除所有权限       | 清除所有权限            |

**权限操作符:** 

1. `+`: 添加权限
2. `-`: 删除权限
3. `=`: 重置权限

**书写格式:** 

```sh
# 给所属用户添加读写权限
chmod u+rw [file]

# 删除所属组写入和运行权限
chmod g-wx [file]

# 给其他用户添加读取权限,删除写入和运行权限, 这里没有声明赋予的权限会被自动删除
chmod o=r

# 修改多个用户权限, 多个用户用 逗号,进行分割. 所属用户给了全部权限,组用户只给了运行,其他用户只给了读写
chmod u+rwx,g-x,o=rw [file]

# 删除所有用户的所有权限
chmod a= [file]
```

**用代表数字修改权限:**

前面所提到的数字代表权限 r(读) = 4, w(写) = 2, x(运行) = 1, 无权限 = 0. 用这四个代表数字可修改文件的权限.

```sh
# 数字表示:
# 所属用户: 7 = 4(r) + 2(w) + 1(x)
# 组用户: 1 = 1(x)
# 其他用户: 6 = 4(r) + 2(w)
chmod 716 [file]
```

**以上命令数字含义:** 
1. 第一个数字 7 为所属用户权限, 4(读取) + 2(写入) + 1(运行) = 7。给出所有权限
2. 第二个数字 1 为所属组权限, 1(运行) = 1，去除读和写的权限
3. 第三个数字 6 为其他用户权限, 4(读取) + 2(读取) = 6。去除运行权限

**删除所有用户的所有权限:** 

```sh
chmod 000 [file]
```

**详细对应表:**

| 权限    | 数值  | 说明         |
| ----- | --- | ---------- |
| `---` | 0   | 无权限        |
| `--x` | 1   | 只有运行权限     |
| `-w-` | 2   | 只有写权限      |
| `-wx` | 3   | 只有写 & 运行权限 |
| `r--` | 4   | 只有读权限      |
| `r-x` | 5   | 只有读 & 运行权限 |
| `rw-` | 6   | 只有读 & 写权限  |
| `rwx` | 7   | 有所有权限      |
