# chmod

change mode, 控制用户对文件的使用权限

**语法:**

```shell
chmod [选项] [path/file]
```

**选项:**

| 选项   | 说明                    |
| ---- | --------------------- |
| `-R` | 递归,将目录内的子文件也一并修改权限    |
| `-c` | 若该文件权限确实已经更改，才显示其更改动作 |
| `-f` | 若该文件权限无法被更改也不要显示错误讯息  |
| `-v` | 显示权限变更的详细资料           |

**用户类型:** 
1. u(user): 所属用户, 文件的创建者
2. g(group):所属组,规定群组内用户的权限
3. o(other):其他用户,不属于user和group,就自动归属于其他用户
4. a(all):所有用户

**文件/目录权限类型:** 
1. r(read): 代表数字 4, 文件读取权限, 读取文件内容,并打印到标准输出
2. w(write): 代表数字 2, 写入权限, 增删改文件的内容
3. x(execute): 代表数字 1, 运行文件权限, 

以上三种权限对文件和目录有着不同的影响,如表格所示:

| 代表字符 | 代表数字 | 权限  | 对文件的权限       | 对目录的权限            |
| ---- | ---- | --- | ------------ | ----------------- |
| r    | 4    | 读取  | 读取文件的内容      | 可用 ls 列出目录内的文件和目录 |
| w    | 2    | 写入  | 增加,删除,修改文件内容 | 创建,删除目录内的文件和目录    |
| x    | 1    | 运行  | 执行运行文件       | 可以cd 进入目录         |
|      | 0    |     | 清除所有权限       | 清除所有权限            |

**权限赋值符号:** 

1. `+`: 添加权限
2. `-`: 删除权限
3. `=`: 重置权限

**用户类型:**

1. `u` (user): 所属用户
2. `g` (group): 所属组用户
3. `o` (other): 其他用户

**书写格式:** 

```shell
给所属用户添加读写权限
chmod u+rw [file]

删除所属组写入和运行权限
chmod g-wx [file]

给其他用户添加读取权限,删除写入和运行权限, 这里没有声明赋予的权限会被自动删除
chmod o=r

修改多个用户权限, 多个用户用 逗号,进行分割. 所属用户给了全部权限,组用户只给了运行,其他用户只给了读写
chmod u+rwx,g-x,o=rw [file]

上面案例用数字表示,所属用户:4(r)+2(w)+1(x)=7,组用户:1(x)=1,其他用户:4(r)+2(w)=6,应写成716:
chmod 716 [file]

删除所有用户的所有权限
chmod a= [file]
```

以上命令中, `=` 后面没有申明的权限, 则不会给相应的权限.

**用代表数字修改权限:**

前面所提到的数字代表权限 r = 4, w = 2, x = 1, 0 = 删除所有权限. 用这四个代表数字可修改文件的权限.

```shell
chmod 765 [file]
```

**以上命令数字含义:** 
1. 第一个数字7 为所属用户权限,读取4 + 写入2 + 运行1 = 7
2. 第二个数字6 为所属组权限, 读取4 + 写入2 = 6.
3. 第三个数字 5 为其他用户权限, 读取4 + 运行1 = 5

**删除所有用户的所有权限:** 

```
chmod 000 [file]
```
