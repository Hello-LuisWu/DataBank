# mv

move, 移动或重命名目录/文件；支持通配符

主要用途：

1. 移动文件/目录
2. 重命名文件/目录
3. 覆盖已有文件
4. 批量移动文件

---

## 语法 

```shell
mv [选项] [path/file] newname
mv [选项] [path] directory
```

---

## 选项

| 选项   | 说明               | 示例                  |
| ---- | ---------------- | ------------------- |
| `-i` | 覆盖文件前询问用户        | `mv -i a.txt b.txt` |
| `-f` | 强制覆盖，不询问         | `mv -f a.txt b.txt` |
| `-n` | 不覆盖已存在文件         | `mv -n a.txt b.txt` |
| `-u` | 目标文件不存在或源文件较新才移动 | `mv -u a.txt dir/`  |
| `-v` | 显示移动过程           | `mv -v a.txt dir/`  |
| `-b` | 覆盖前创建备份          | `mv -b a.txt b.txt` |
| `-S` | 修改备份文件后缀         | `mv -S .bak a b`    |

---

## 实例

### 00 重命名

将文件名为 `aaa.txt` 的文件改名为 `bbb.txt`，修改目录名同理。

```sh
mv aaa.txt bbb.txt

# 格式：
mv 原文件/目录名 新文件/目录名
```

### 01 移动单个文件

```sh
mv test.txt docs/
```

### 2 移动并重命名文件

```sh
mv test.txt ~/test/hello.txt
```
就 `test.txt` 移动到家目录下的 `test` 目录下，并改名为 `hello.txt`
### 03 移动多个文件

```sh
mv a.txt b.txt c.txt docs/
```

将文件移动到 docs 目录下

### 04 移动目录

将 info 目录放入 logs 目录中。注意，如果 logs 目录不存在，则该命令将 info 改名为 logs。

```sh
mv info/ logs
```

### 5 使用通配符批量移动

将 `/usr/runoob` 下的所有文件和目录，用通配符移到当前目录下：

```sh
mv /usr/runoob/*  . 
```

**移动所有 txt 文件:**

```sh
mv *.txt docs/
```

**移动所有图片:**

```sh
mv *.png images/
```

### 6 覆盖文件

若目标文件已存在 `backup/a.txt`

```sh
mv a.txt backup/
```

会覆盖原先 `backup` 目录下的 `a.txt` 文件

### 07 -i 覆盖前询问（推荐）

```sh
mv -i a.txt backup/

# 提示：
mv: overwrite 'backup/a.txt'?

# 按 y 确认覆盖
```

### 08 -f 强制覆盖

```sh
mv -f a.txt backup/

# 适合脚本文件覆盖：
mv -f build/* /var/www/html/
```

### -n 09 不覆盖已有文件

若 backup 目录里有 a.txt 文件

```sh
mv -n a.txt b.txt c.txt backup/
```

a.txt 不会被覆盖

### 10 -v 显示移动过程

```sh
mv -v test.txt docs/

# 输出：
renamed 'test.txt' -> 'docs/test.txt'
```

## 11 -u 只移动更新的文件

```sh
mv -u *.txt backup/
```

规则：

| 情况        | 结果  |
| --------- | --- |
| 目标不存在     | 移动  |
| 源文件更新时间更新 | 移动  |
| 源文件较旧     | 不移动 |

### 12 -b 创建备份

```sh
mv -b a.txt b.txt
```

若 `b.txt` 存在，先备份 `b.txt~` 然后 `a.txt → b.txt`

### 13 -S 指定备份后缀

```sh
mv -b -S .bak a.txt b.txt
```

备份后缀为 .bak

### 14 移动技巧

```sh
# 移动到上一级目录
mv file.txt ../

# 移动到当前用户目录
mv ~/text/a.txt ./

# 使用绝对路径移动
mv nginx.conf /etc/nginx/

# 移动目录到指定位置
mv website /var/www/
```

### 常用组合

| 需求     | 命令                  |
| ------ | ------------------- |
| 移动文件   | `mv file dir/`      |
| 重命名文件  | `mv old new`        |
| 移动目录   | `mv dir target/`    |
| 显示过程   | `mv -v file dir/`   |
| 覆盖询问   | `mv -i file dir/`   |
| 强制覆盖   | `mv -f file dir/`   |
| 禁止覆盖   | `mv -n file dir/`   |
| 只更新文件  | `mv -u file dir/`   |
| 移动并显示  | `mv -iv file dir/`  |
| 递归移动目录 | `mv -v dir target/` |
