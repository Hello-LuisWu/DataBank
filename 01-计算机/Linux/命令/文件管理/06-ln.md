# ln

link, 创建文件的链接；默认创建硬链接

Linux 中链接分为两种：

1. **硬链接（Hard Link）**
2. **符号链接（Symbolic Link / Soft Link）**

## 选项

| 参数   | 全称                  | 作用          | 示例                      |
| ---- | ------------------- | ----------- | ----------------------- |
| `-s` | symbolic            | 创建符号链接（软链接） | `ln -s file link`       |
| `-f` | force               | 强制覆盖目标文件    | `ln -sf a b`            |
| `-i` | interactive         | 覆盖前询问       | `ln -i file link`       |
| `-v` | verbose             | 显示创建过程      | `ln -v file link`       |
| `-n` | no-dereference      | 不跟随目标软链接    | `ln -snf new old`       |
| `-r` | relative            | 创建相对路径软链接   | `ln -sr src dst`        |
| `-T` | no-target-directory | 将目标作为普通文件处理 | `ln -T file link`       |
| `-b` | backup              | 覆盖前备份目标     | `ln -b file link`       |
| `-S` | suffix              | 指定备份后缀      | `ln -bS .bak file link` |
| `-L` | logical             | 跟随符号链接（默认）  | `ln -L`                 |
| `-P` | physical            | 链接符号链接本身    | `ln -P`                 |

## 语法

```sh
ln [选项] 源文件 目标文件
```

---

## 实例

### 创建文件硬链接

```sh
ln a.txt b.txt

# 查看：
ls -li

# 结果：
12345 -rw-r--r-- 2 user user a.txt
12345 -rw-r--r-- 2 user user b.txt

# 链接结构：
        inode 12345
            |
     ----------------
     |              |
   a.txt          b.txt
```

文件数量增加的同时，链接文件和源文件的 inode 也相同

### 创建软链接

```sh
ln -s /usr/bin/python3 python

# 查看：
ls -l

# 显示：
python -> /usr/bin/python3

# 链接结构：
python
   ↓
路径字符串
   ↓
/usr/bin/python3
```

**硬链接 vs 软链接：**

1. **软链接**(符号链接) Symbolic Link / Soft Link：
	1. 软链接会占空间，软链接本身就是一个独立的小文件。
	2. 软链接，类似于Windows 的快捷方式
	3. 软链接可以 跨文件系统 ，硬链接不可以
	4. 软链接可以对一个不存在的文件名进行链接
	5. 软链接可以对目录进行链接
	6. 删除源文件会失效
2. **硬链接** Hard Link：
	1. 修改链接文件，源文件也会同步修改
	2. 不允许给目录创建硬链接
	3. 不能跨文件系统，不同磁盘 inode 不共享
	4. 删除源文件不影响
	5. 硬链接是源文件副本，但几乎不占空间，只增加一个文件名目录项。
	6. 硬链接 inode 与源文件完全相同
	7. 不可以链接目录，因为容易破坏文件系统结构。

**软硬链接对比表：**

| 区别      | 硬链接   | 软链接     |
| ------- | ----- | ------- |
| 参数      | 无     | `-s`    |
| 指向      | inode | 文件路径字符串 |
| 占用空间    | 几乎不占  | 占一点空间   |
| 大小      | 文件大小  | 路径长度    |
| 跨文件系统   | ❌     | ✅       |
| 链接目录    | ❌     | ✅       |
| 链接不存在文件 | ❌     | ✅       |
| 删除源文件   | 仍可用   | 失效      |
| inode   | 相同    | 不同      |

### 给配置文件创建快捷入口

```sh
ln -s ~/.config/nvim ~/.vim

# 链接架构：
.vim 
| 
└── ~/.config/nvim
```

软链接可以链接目录

### `-f` 强制覆盖链接

```sh
ln -sf a b
```

若链接文件有重名的，就强制覆盖

### 显示创建过程

```sh
ln -sv source target

# 输出：
target -> source
```

###  创建相对路径软链接

```sh
ln -sr /home/user/project/file file

# 生成：
file -> ../project/file
```


不加 `-r` 默认创建绝对路径：
- 相对路径是相对于链接文件自身的位置
- 创建相对路径移优点：动整个目录后仍然有效
- 创建相对路径移缺点：移动链接文件位置则失效
