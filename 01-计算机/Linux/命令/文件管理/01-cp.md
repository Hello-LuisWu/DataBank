# cp

copy, 复制目录/文件；支持通配符

## 语法

```sh
cp [选项] [path/file]
```

---

## 选项

| 选项   | 说明                      |
| ---- | ----------------------- |
| `-r` | 递归操作, 复制目录和目录下所有的文件和子目录 |
| `-v` | 打印复制过程                  |
| `-i` | 若有相同文件名,会询问是否要覆盖        |
| `-f` | 强制复制，覆盖目标文件而不提示         |
| `-p` | 保留文件属性，比如最后修改时间         |
| `-s` | 创建符号链接（软链接）而不是复制文件。     |
| `-l` | 创建硬链接而不是复制文件。           |

---

## 实例

**00. 复制多个文件/目录:** 

```sh
# 以上命令中, 最后一个 dir4 为目标文件夹, 把前三个dir1, dir2, dir3 里面的文件复制到 dir4 中
cp -r dir1/a.txt dir2/ dir3/a.txt dir4/
```

 **1. 复制文件到目标目录**

```sh
cp file.txt /path/to/destination/
```

 **2. 复制文件并重命名**

```sh
cp file.txt /path/to/destination/newfile.txt
```

**3. 递归复制目录**

```sh
cp -r /path/to/source_dir /path/to/destination/
```

**4. 保留文件属性**

```sh
cp -p file.txt /path/to/destination/
```

**5. 创建硬链接或符号链接**

```sh
cp -l file.txt /path/to/destination/  # 创建硬链接
cp -s file.txt /path/to/destination/  # 创建符号链接
```

**6. 复制多个文件到目录**

```sh
cp file1.txt file2.txt /path/to/destination/
```

**7. 复制多个文件到目录**

```sh
cp file1.txt file2.txt /path/to/destination/
```

**8. 使用通配符复制**

```sh
cp *.txt /path/to/destination/
```

**9. 结合 find 命令复制特定文件**

```sh
find /path/to/source -name "*.log" -exec cp {} /path/to/destination/ \;
```

查找并复制所有 .log 文件到目标目录。
以上只是 cp 命令的一些常见用法，你可以通过运行 `man cp` 命令查看更多选项和用法。
