# tail

tail 查看文件最尾部的内容

## 语法

```sh
tail [参数] [文件]
```

## 选项

| `-f`        | 循环读取                    |
| ----------- | ----------------------- |
| `-q`        | 不显示处理信息                 |
| `-v`        | 显示详细的处理信息               |
| `-c <数目>`   | 显示的字节数                  |
| `-n <行数>`   | 显示文件的尾部 n 行内容           |
| `--pid=PID` | 与-f合用,表示在进程ID,PID死掉之后结束 |

## 实例

**01.** 要显示 notes.log 文件的最后 10 行，请输入以下命令：

```sh
tail notes.log         # 默认显示最后 10 行
```

**02.** 要跟踪名为 notes.log 的文件的增长情况，请输入以下命令：

```sh
tail -f notes.log
```

此命令显示 notes.log 文件的最后 10 行。当将某些行添加至 notes.log 文件时，tail 命令会继续显示这些行。 显示一直继续，直到您按下（Ctrl-C）组合键停止显示。

**03.** 显示文件 notes.log 的内容，从第 20 行至文件末尾:

```sh
tail -n +20 notes.log
```

**03.** 显示文件 notes.log 的内容，从第 20 行至文件末尾:

```sh
tail -n +20 notes.log
```

**04.** 显示文件 notes.log 的最后 10 个字符:

```sh
tail -c 10 notes.log
```
