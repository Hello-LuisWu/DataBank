
# 曝光三要素

|要素|参数变化|进光量/亮度影响|
|---|---|---|
|**光圈（Aperture）**|f值越小 → 光圈越大|进光越多 → 画面越亮|
|**快门速度（Shutter）**|速度越慢（如1/30s）|进光越多 → 画面越亮|
|**感光度（ISO）**|ISO值越高|传感器越敏感 → 画面越亮（但噪点也越多）|

> **“高感”** ：通常指高ISO值下的画质表现。高感好的相机在暗光下使用高ISO时，画面仍能保持干净、噪点可控。

## 1 光圈（Aperture）控制 进光量 景深

规律：

| 光圈  | F值        | 进光量 | 景深  |
| --- | --------- | --- | --- |
| 大光圈 | F1.2/F1.4 | 多   | 浅   |
| 小光圈 | F8/F16    | 少   | 深   |

口诀： F值越小，光圈越大，进光越多，背景越虚化。

## 2 快门速度（Shutter Speed）控制 进光时间 动态效果

规律：

| 快门  | 效果             |
| --- | -------------- |
| 慢快门 | 进光多，画面亮，容易产生拖影 |
| 快快门 | 进光少，冻结运动       |

例如：

慢快门：
- 夜景车流
- 水流丝滑效果

高速快门：
- 飞鸟
- 运动瞬间

## 3 感光度 ISO

ISO表示相机传感器对光线的敏感程度。

| ISO   | 画质   | 噪点控制 |
| ----- | ---- | ---- |
| 低ISO  | 画质好  | 噪点少  |
| 高 ISO | 暗光更亮 | 噪点增加 |

> 总结：光圈开大、快门放慢，都会增加进光，画面变亮。

## 4 曝光调整顺序

实际拍摄建议：

### 4.1 确定光圈

根据需求决定：
- 想虚化背景：→ 大光圈
- 想全部清晰：→ 小光圈

### 4.2 调整快门

通过快门控制亮度。

### 4.3 调整ISO

如果：
- 光圈不能改变
- 快门已经限制

再通过提高ISO来调整亮度，但相应可能会增加噪点从而降低画质

### 4.4 实操拍摄思路总结

1. 优先定**光圈**：根据想要的景深效果设置。
2. 再调**快门速度**：控制画面整体明暗。
3. 光圈、快门调到极限还达不到理想亮度，再改动**ISO**。

## 5 各场景曝光建议

| 场景        | 建议设置                       | 备注                |
| --------- | -------------------------- | ----------------- |
| **夜景手持**  | 大光圈（f/1.4～f/2.8）+ 适当提高ISO  | 避免低速快门导致模糊，或使用三脚架 |
| **夜景三脚架** | 小光圈（f/8～f/11）+ 低ISO + 慢速快门 | 可获得大景深且画质纯净       |
| **夕阳/日出** | 光圈 f/8～f/16                | 确保太阳星芒效果，画面整体清晰   |
| **眺望远景**  | 小光圈（f/8～f/16）+ 无限远对焦       | 保证前后景均清晰          |
| **日常快照**  | 自动/半自动模式                   | 快速抓拍可用P档或A档       |

## 6 视频曝光特殊规则

拍摄视频时，快门速度通常设置为**帧速率的两倍（倒数）** ：

- 60fps → 快门速度设为 **1/125s**（最接近1/120s的常用值）
- 30fps → 快门速度设为 **1/60s**
- 24fps → 快门速度设为 **1/50s**

> **原因**：遵循“180度快门规则”，可获得自然的运动模糊效果，使视频画面流畅不卡顿。

## 7 摄影快速口诀

- 景深：光圈越大，焦距越长，距离越近，景深越浅。
- 曝光：光圈控制进光和虚化，快门控制时间和运动，ISO控制暗光能力。
- 长焦：拉近距离，压缩空间，虚化背景，突出主体。
- 拍摄流程：先想效果 → 定光圈 → 调快门 → 补ISO。
