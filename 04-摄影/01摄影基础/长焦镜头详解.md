# 长焦镜头详解

## 1 长焦特点

长焦镜头类似望远镜：
- 焦距长
- 视角窄
- 可以拍摄远处物体
- 放大远处主体

 常见焦段：
- 24mm广角：看到更大的范围
- 85mm标准人像：正常视角
- 200mm长焦：可以拉近远处景物

## 2 长焦镜头的四大特点

### 2.1. 空气切割机

长焦可以产生明显背景虚化：

- 背景被压缩成色块
- 主体与背景分离
- 画面具有空间层次感

因此很多摄影师称长焦为 空气切割机

### 2.2 空间压缩

长焦会缩短画面中物体之间的距离。

例如：

```
# 实际距离：
摄影师 ------------------- 山

# 长焦镜头视野：
摄影师 ---- 山
```

人物和远处山峰看起来更加接近。

### 2.3 透视弱化

长焦镜头：
- 透视变化小
- 畸变少：画面边缘变形轻微，横平竖直，还原被摄体本真形态
- 主体比例更加自然

适合：
- 建筑
- 人像
- 风景压缩

### 2.4 浅景深效果

小光圈也能虚化，即使光圈不大也能获得明显虚化效果

因为焦距长，即使：
- F5.6
- F8

也可以产生明显背景虚化。

## 3 长焦镜头使用场景

### 3.1 人像摄影

优势：
- 背景虚化强
- 人物脸部变形少
- 可以减少杂乱背景

常用：
- 85mm
- 135mm

### 3.2 街拍摄影

长焦视角窄：
- 可以减少无关元素进入画面
- 不需要复杂布景
- 更容易突出主体

### 3.3 运动摄影

长焦可以增强速度感：
- 虚化背景快速移动
- 突出运动主体

适合：
- 赛车
- 足球
- 动物奔跑

### 3.4. 风景摄影

长焦拍树 + 远处山等风景

使用长焦后：
- 树和山距离被压缩
- 看起来像融合在一起

相比广角：
- 广角适合展现宏大空间
- 长焦适合提取局部风景
