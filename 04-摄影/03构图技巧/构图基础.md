# 构图基础

摄影构图是通过**安排画面中的主体、线条、空间、光影和元素关系**，让照片更有视觉吸引力和表达力。常见构图可以分为以下几大类：

## 1. 基础比例构图

| 构图方式                           | 英文                   | 特点                    | 适合场景       |
| ------------------------------ | -------------------- | --------------------- | ---------- |
| [三分法构图](01-比例构图/01-三分法构图.md)   | Rule of Thirds       | 将画面横竖各分三份，主体放在交点或分割线上 | 人像、风景、街拍   |
| [黄金比例构图](01-比例构图/02-黄金比例构图.md) | Golden Ratio         | 按黄金分割比例安排主体，比三分法更自然   | 人像、建筑、艺术摄影 |
| [黄金螺旋构图](01-比例构图/03-黄金螺旋构图.md) | Golden Spiral        | 主体沿螺旋线布局，引导视觉中心       | 人像、花卉、静物   |
| [对角线构图](01-比例构图/04-对角线构图.md)   | Diagonal Composition | 利用斜线增加动感和空间感          | 运动、建筑、街拍   |

## 2. 线条引导类构图

| 构图方式                         | 英文                  | 特点             | 常见元素       |
| ---------------------------- | ------------------- | -------------- | ---------- |
| [引导线构图](02-线条引导/01-引导线构图.md) | Leading Lines       | 利用线条引导观众视线到主体  | 道路、河流、栏杆   |
| [汇聚线构图](02-线条引导/02-汇聚线构图.md) | Converging Lines    | 多条线向一点汇聚，形成空间感 | 铁轨、建筑、走廊   |
| [对角线构图](02-线条引导/03-对角线构图.md) | Diagonal Lines      | 斜线制造速度和张力      | 桥梁、人物动作    |
| [曲线构图](02-线条引导/04-曲线构图.md)   | Curved Lines        | 柔和自然，引导视觉移动    | 海岸、道路、人体曲线 |
| [S形构图](02-线条引导/05-S形构图.md)   | S-Curve Composition | 形成视觉流动感        | 河流、山路、人体   |

## 3. 空间关系构图

| 构图方式                         | 英文                     | 特点           | 应用       |
| ---------------------------- | ---------------------- | ------------ | -------- |
| [前景构图](03-空间关系/01-前景构图.md)   | Foreground Composition | 利用前景增加层次     | 风景摄影     |
| [框架构图](03-空间关系/02-框架构图.md)   | Frame within Frame     | 利用物体形成框架突出主体 | 门窗、树枝、建筑 |
| [留白构图](03-空间关系/03-留白构图.md)   | Negative Space         | 保留大量空白突出主体   | 极简、人像    |
| [层次构图](03-空间关系/04-层次构图.md)   | Layer Composition      | 前中后景形成空间深度   | 风景、建筑    |
| [开放式构图](03-空间关系/05-开放式构图.md) | Open Composition       | 画面元素延伸到画外    | 街拍、纪实    |

## 4. 对称和平衡类构图

| 构图方式                        | 英文                      | 特点           | 场景    |
| --------------------------- | ----------------------- | ------------ | ----- |
| [对称构图](04-对称和平衡/01-对称构图.md) | Symmetrical Composition | 左右或上下高度平衡    | 建筑、倒影 |
| [中心构图](04-对称和平衡/02-中心构图.md) | Center Composition      | 主体放在中央，突出稳定感 | 人像、建筑 |
| [平衡构图](04-对称和平衡/03-平衡构图.md) | Balanced Composition    | 不对称但视觉重量平衡   | 风景、静物 |
| [镜像构图](04-对称和平衡/04-镜像构图.md) | Reflection Composition  | 利用反射形成对称     | 湖面、玻璃 |

## 6. 人像摄影常用构图

| 构图方式  | 特点        |
| ----- | --------- |
| 三分法人像 | 人眼放在三分线附近 |
| 半身构图  | 突出表情和姿态   |
| 头像特写  | 强调五官和情绪   |
| 环境人像  | 人物与环境结合   |
| 低角度人像 | 增强力量感     |
| 高角度人像 | 显得柔和、纤细   |
| 留白人像  | 增加故事感     |

## 7. 风景摄影常用构图

| 构图方式     | 特点        |
| -------- | --------- |
| 三分法地平线   | 天空和地面比例平衡 |
| 前景+主体+背景 | 增强空间深度    |
| 对称倒影     | 增强秩序感     |
| 引导线      | 引导视线进入远方  |
| 全景接片     | 展现广阔场景    |
| 框架式风景    | 增强层次      |

## 8. 建筑摄影构图

|构图方式|特点|
|---|---|
|仰拍构图|表现建筑高度|
|俯拍构图|表现空间结构|
|对称构图|表现建筑秩序|
|几何构图|强调线条和形状|
|重复构图|表现规律美感|

## 9. 创意构图

|构图方式|特点|
|---|---|
|双重曝光|两个画面融合|
|框中框|多层空间关系|
|视觉错位|制造趣味效果|
|极简构图|用最少元素表达主题|
|负空间|强调孤独、宁静|
|抽象构图|强调形状、颜色、纹理|

```text
基础构图
│
├── 三分法
├── 中心构图
├── 对称构图
│
↓
空间构图
│
├── 前景
├── 框架
├── 留白
├── 层次
│
↓
线条构图
│
├── 引导线
├── 对角线
├── S形曲线
│
↓
高级构图
│
├── 黄金比例
├── 色彩关系
├── 光影关系
├── 视觉叙事
```

实际拍摄中最常用的组合：

- **风景：三分法 + 前景 + 引导线**
- **人像：三分法 + 留白 + 虚实对比**
- **街拍：框架 + 决定性瞬间**
- **建筑：对称 + 几何线条**
- **静物：中心构图 + 光影对比**
