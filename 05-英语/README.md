# 🇬🇧 English 英语学习资源库

本目录用于整理英语学习相关资料，按照英语能力成长路径进行分类，覆盖从零基础入门到高级应用的完整学习体系。

目标：

- 建立系统化英语学习路线
- 整理优质学习资料
- 降低学习资料查找成本
- 形成长期可维护的英语知识库

英语学习建议按照以下顺序：

```text
基础阶段
    ↓
发音
    ↓
核心词汇
    ↓
基础语法
    ↓
听力输入
    ↓
口语表达
    ↓
阅读提升
    ↓
写作训练
    ↓
高级应用
```

# 🎯 学习目标

## 🌱 初级阶段

目标：

- 掌握英语发音规则
- 积累 1000~3000 核心词汇
- 理解基础语法
- 能完成简单交流

## 🌿 中级阶段

目标：

- 阅读日常英文内容
- 听懂慢速英语
- 进行日常交流
- 独立写简单文章

## 🌳 高级阶段

目标：

- 阅读英文书籍
- 使用英语学习专业知识
- 观看英文影视
- 进行工作交流

# 📌 学习原则

## 🔁 长期输入

每天保持：

- 阅读
- 听力
- 单词积累

## 🗣️ 主动输出

不要只学习：

- 背单词
- 学语法

还需要：

- 说出来
- 写出来

## ⏳ 持续积累

英语学习是长期过程：

> 每天进步一点，长期会产生巨大变化。

# 🗂️ 文件管理规范
