# 础形容词（Adjectives）

形容词（Adjectives）用于描述**人、物、地点、状态、感觉、性质**。  
以下整理英语入门阶段最高频形容词，并列出常见多义中文。

## 1. 基础性质形容词（Basic Qualities）

| 英语     | 音标       | 多个意思的中文             |
| ------ | -------- | ------------------- |
| good   | /ɡʊd/    | 好的；优秀的；善良的；有益的；合适的  |
| bad    | /bæd/    | 坏的；糟糕的；严重的；有害的；不舒服的 |
| great  | /ɡreɪt/  | 伟大的；很好的；巨大的；重要的；非常的 |
| small  | /smɔːl/  | 小的；少量的；年轻的；小规模的     |
| big    | /bɪɡ/    | 大的；重要的；年龄大的；成功的     |
| large  | /lɑːrdʒ/ | 大的；大量的；广泛的；宽大的      |
| little | /ˈlɪtəl/ | 小的；少量的；年幼的；短时间的     |
| long   | /lɔːŋ/   | 长的；长期的；远的；渴望的       |
| short  | /ʃɔːrt/  | 短的；矮的；不足的；简短的       |
| high   | /haɪ/    | 高的；高度的；高级的；昂贵的      |
| low    | /loʊ/    | 低的；少量的；低级的；低落的      |
| tall   | /tɔːl/   | 高的（人、建筑）；夸大的        |
| wide   | /waɪd/   | 宽的；广泛的；充分的          |
| narrow | /ˈnæroʊ/ | 窄的；狭隘的；有限的          |
| thick  | /θɪk/    | 厚的；粗的；浓密的；密集的       |
| thin   | /θɪn/    | 薄的；瘦的；稀薄的；微弱的       |
