# 👤 人物与称呼（People）英语词汇

| 英语       | 音标          | 多个意思的中文             |
| -------- | ----------- | ------------------- |
| I        | /aɪ/        | 我；本人；自我（哲学概念中的“自我”） |
| me       | /miː/       | 我（宾格）；自己；个人         |
| my       | /maɪ/       | 我的；属于我的；与我有关的       |
| mine     | /maɪn/      | 我的（东西）；矿；矿井         |
| myself   | /maɪˈself/  | 我自己；亲自；本人           |
| you      | /juː/       | 你；你们；任何人（泛指）        |
| your     | /jɔːr/      | 你的；你们的；属于你的         |
| yours    | /jɔːrz/     | 你的东西；你们的东西          |
| yourself | /jɔːrˈself/ | 你自己；亲自；本人           |
| he       | /hiː/       | 他；男性；某个男性           |
| him      | /hɪm/       | 他（宾格）；男性；某人         |
| his      | /hɪz/       | 他的；他的东西             |
| himself  | /hɪmˈself/  | 他自己；亲自              |
| she      | /ʃiː/       | 她；女性                |
| her      | /hɜːr/      | 她（宾格）；她的；女性         |
| hers     | /hɜːrz/     | 她的东西                |
| herself  | /hɜːrˈself/ | 她自己；亲自              |
| it       | /ɪt/        | 它；这个事物；情况；天气（非人称主语） |
| its      | /ɪts/       | 它的；属于它的             |
| itself   | /ɪtˈself/   | 它自己；本身              |
