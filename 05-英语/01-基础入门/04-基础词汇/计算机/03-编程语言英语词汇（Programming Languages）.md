# 编程语言英语词汇（Programming Languages）

编程语言（Programming Languages）词汇主要用于学习 **Python、JavaScript、Java、C/C++、Rust、Go、Shell、Web 开发、软件工程**等方向。  
表格包含：**英语、音标、多个中文含义**。
